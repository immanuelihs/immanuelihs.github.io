§02 · Research & Systems

[A] Agent reliability & factuality

Three systems, one line: verify what an agent says, catch what it leaves out, then make the safe path the only path.

ProvenanceGuard

Multiverse Computing · 2025–26

First source-aware factuality verifier for MCP-based agents — a fine-tuned Router+NLI verifier that catches subtle hallucination and cross-source conflation in tool calls.

→ +47% grounding accuracy in accuracy-sensitive domains

arXiv:2606.18037

Lacuna

Multiverse Computing · 2025–26

First runtime omission-detection gate for tool-using agents — closes the recall-side blind spot that hallucination checkers structurally miss, in law- and medicine-domain agents. A fine-tuned atomic-entailment scorer beats an LLM-judge baseline at roughly 20× smaller model size.

→ omission F1 0.603 → 0.747

→ F1 0.747 vs. 0.618 (LLM-judge baseline), ~20× smaller model

ProvenanceGuard and Lacuna are both now being deployed for an enterprise technology partner.

TraceForge

Multiverse Computing · patent filed, EP 26382950.9

Human-gated framework that hardens stochastic agent behavior into immutable workflow DAGs for regulated industries.

→ 73% of production requests served from frozen DAGs

→ −38% redundant executions

[B] Efficient inference

Speculative decoding

Multiverse Computing · H200

Training-free, dynamic-pruning self-speculative decoding across the Gemma, Qwen3, and Mistral model families. Fully lossless — output distribution is unchanged.

→ 1.34–1.67× mean latency reduction (2.88× peak)

Structured pruning lineage

L&T Technology Services · 3 patents

Multi-criteria pruning algorithms for medical-imaging CNNs, later generalized into a patented no-code compression platform for LLM and deep-learning models.

→ 70% compression, <1% accuracy drop, beating SoTA baselines
